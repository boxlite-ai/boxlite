# Template icons

Brand SVGs added for the tested catalog (Jupyter, SciPy, R, FFmpeg, Qdrant,
PostgreSQL and k6) come from https://github.com/simple-icons/simple-icons/tree/develop/icons
under CC0; see SIMPLE-ICONS-LICENSE.txt. SVG fill colors are tuned for the console.
Go and Rust reuse existing dashboard assets. Python, Node, Debian and Lightpanda
reuse existing template artwork. Other entries use distinct task pictograms from
the dashboard icon system, not invented project logos.

Assets are bundled locally; rendering never depends on a remote image service.

Expanded catalog: uv, Bun, Apache Maven and GNU marks also use Simple Icons CC0.
GCC uses the GNU mark; Browserless Chromium uses the existing Chromium mark.
