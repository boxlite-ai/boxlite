## TL;DR

Go cannot configure guest SSH; add `Box.SSH()` with `Configure`, `Status`, and
`Disable` over the existing C callback bridge, freeing each status once and
redacting printed configuration.

## Scope

Dated design study, 2026-10-27. Parent design: [#2053](https://github.com/boxlite-ai/boxlite/issues/2053)
(Python, Node.js, C). Source references are pinned to `db33689c`.

| Item | Decision |
|------|----------|
| API | `Box.SSH() *SSH`; `Configure(ctx, SSHConfig)`, `Status(ctx)`, `Disable(ctx)` return `(*SSHStatus, error)` |
| Types | `SSHConfig{ListenAddress, HostPrivateKey, Accounts}`, `SSHAccount{Login, AuthorizedKeys, CA *SSHCAConfig}`, `SSHCAConfig{PublicKey, Principal}`, `SSHStatus{Enabled, Generation uint64, ListenAddress, HostPublicKey, HostKeyFingerprint}` |
| Ownership | `SSH` holds only its `*Box`; no native handle, no `Close` |
| Errors | Closed box → `ErrInvalidState` "box is closed"; closed runtime → `ErrRuntimeClosed`; cancellation → `ctx.Err()` |
| Non-goals | SSH client, Go key parsing/generation, retries, new dependencies, `fmt.Formatter` |

Acceptance: Go→C→Rust REST loopback tests (routes, wire body, status, errors,
`>2^53` generation, redaction, cancel, runtime close, late free); local VM
tests (cold status/disable, reconfigure, repeated disable, explicit-command
`Start`).

Alternatives:

- **JSON tags on public types** — rejected: nil→`[]` still needs a copy.
- **Separate SSH native handle** — rejected: C takes `CBoxHandle*`.
- **No pre-checks (match Box methods)** — rejected: closed box would be
  `InvalidArgument`, and a configure after `Runtime.Close` reaches the server.
- **C-level `ensure_runtime_live` in `spawn_op`** — deferred: it changes the
  shipped C contract; a C SDK follow-up candidate.

## How it works

```text
SSH.Configure ─ json(wire) ─▶ boxlite_box_ssh_configure ─▶ Tokio ▶ SshHandle
     ▲                                                          │
     └─ chan sshStatusResult ◀─ goBoxliteOnSSHStatus ◀─ drain ◀─┘
```

1. Guard: nil or closed box → `ErrInvalidState` "box is closed"; closed
   `runtime.closing` → `ErrRuntimeClosed` before any native call. As in
   existing Box methods, `b.handle` is unsynchronized; concurrent
   `Box.Close`/`Runtime.Close` races the guard (known risk).
2. `Configure` maps to unexported snake_case wire structs; the C string is freed after the call.
3. One helper registers the handle, calls the native function, and selects on
   result, `ctx.Done()`, and `closing`; abandoned calls use `drainAndDelete`.
4. `goBoxliteOnSSHStatus`: `h == 0` → free; lost claim → free; won claim →
   copy fields and free before the channel type assertion, then send.
   `Generation` copies `uint64_t` directly. Every free goes through `freeSSHStatus`.
5. `String`/`GoString` print
   `SSHConfig{ListenAddress:"0.0.0.0:2222" HostPrivateKey:[redacted] Accounts:[SSHAccount{Login:"alice" AuthorizedKeys:[redacted] CA:[redacted]}]}`.

Trade-off: cancellation returns promptly but cannot undo an applied
configuration (core contract). Estimated production additions: ~190.

## Validation

| Claim / risk | Check | Expected |
|--------------|-------|----------|
| Routes and REST body | REST loopback records method, path, body | `POST/GET/DELETE /v1/boxes/box1/ssh`; `authorized_keys:[]`, `ca:null` or CA object |
| Go→C JSON | Unit test of the wire encoder; nil-keys configure via REST | `[]` and no `ca` key; configure succeeds, not `invalid SSH configuration` |
| Status copy | Server returns generation `2^64-1` | Exact `uint64` |
| Error mapping | 409 `invalid_state`, 400 `invalid_argument` | `ErrInvalidState` / `ErrInvalidArgument`; no key material in message |
| Redaction | `%v %+v %s %#v` on config, account, CA | Sentinel absent; login shown |
| Cancel / close | Held reply, then cancel or `rt.Close` | `context.Canceled` / `ErrRuntimeClosed` promptly |
| Late free | Counting `freeSSHStatus` after an abandoned call is answered | Exactly one free per status |
| Lost-claim / `h == 0` / wrong channel type | Dev-only fixture invokes the callback with a C-allocated status and a counting free | One free each |
| Closed box / runtime | Call after `Close` returns | State error / `ErrRuntimeClosed`; no request sent |
| VM lifecycle | Local VM journeys A and B | Cold disabled gen 0; gen 1 then 2; disable keeps 2; explicit cmd `InvalidState` until `Start` |

Observed results go in the verification report.
