# `apps/api-client-go` 详细解读

## 一句话定位

`apps/api-client-go` 是 **`apps/api` 的 Go HTTP 客户端 SDK**,**完全由 [OpenAPI Generator](https://openapi-generator.tech) 从 `apps/api` 导出的 `openapi.json` 自动生成**,服务 `apps/cli`、`libs/sdk-go`、`apps/otel-collector/exporter` 等所有需要调用 BoxLite 平台 REST API 的 Go 进程。

> 文件头每个 `.go` 都标着:
> ```
> // Code generated by OpenAPI Generator (https://openapi-generator.tech); DO NOT EDIT.
> ```
> **不要手改任何文件**,改完再生成就全没了。要改请改 `apps/api` 的源或生成脚本。

| 项目工具链 | Nx + `@nx-go/nx-go`(`project.json`) |
| 默认 Server | `http://localhost:3000`(在 `configuration.go:97`) |

> 注意:模块路径里写的是 `libs/api-client-go`,但仓库里实际位置是 `apps/api-client-go/`。`project.json` 里也是 `"sourceRoot": "libs/api-client-go"`——这是 Nx workspace 历史路径,实际构建以仓库内真实路径为准。

### Model 层

177 个 model 文件,涵盖请求体、响应体、enum、`oneOf`/`anyOf` 联合类型。命名是 OpenAPI schema 名直接转 Go 命名(`structPrefix=true` 但实际效果是保留原名,例如 `ApiKeyResponse`、`Sandbox`、`CreateSandbox`)。

每个 model 文件套路一致:

```go
// model_api_key_response.go
type ApiKeyResponse struct {
    Name        string       `json:"name"`
    Value       string       `json:"value"`
    CreatedAt   time.Time    `json:"createdAt"`
    Permissions []string     `json:"permissions"`
    ExpiresAt   NullableTime `json:"expiresAt"`              // ← 区分 null / 不存在
    AdditionalProperties map[string]interface{}              // ← 额外字段透传
}
type _ApiKeyResponse ApiKeyResponse                          // 用于 UnmarshalJSON 时避免递归

// 编译时检查:实现 MappedNullable
var _ MappedNullable = &ApiKeyResponse{}

// + NewApiKeyResponse / NewApiKeyResponseWithDefaults
// + 每个字段一对 Get/Set/HasXxx
// + MarshalJSON / UnmarshalJSON / ToMap
// + NullableApiKeyResponse 包装类型
```

要点:
- **`NullableXxx`**:`NullableString`/`NullableTime`/`NullableInt32`...(`utils.go:165+`)用一个 `value + isSet` 的结构区分 JSON `null`、字段缺失、零值三种情况。OpenAPI `nullable: true` 的字段会被生成成 `NullableT`。
- **`AdditionalProperties`**:Spec 里 `additionalProperties` 默认开启(`disallowAdditionalPropertiesIfNotPresent=false`),所以服务端新增字段不会让旧客户端炸,会被装进 `AdditionalProperties` 里。
- **`MappedNullable` 接口**:统一所有 model 都能 `ToMap()`,被 `parameterAddToHeaderOrQuery` / `parameterValueToString` 用于序列化到 query/header。

## 核心架构:三层一图

```
            ┌───────────────────────────────────────────────┐
            │                  APIClient                    │
            │  (client.go: 持有 cfg + 19 个 *XxxAPIService) │
            └───────────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
  SandboxAPIService    ToolboxAPIService       ...其他 17 个
        │                                       (api_*.go)
        │  Builder 链:
        │   svc.CreateSandbox(ctx)                       ← 构造 Request 对象
        │      .XBoxLiteOrganizationID("...")            ← 链式选填参数
        │      .CreateSandbox(body)                      ← 必填 body
        │      .Execute()                                ← 真正发请求
        ▼
  *SandboxAPICreateSandboxRequest
        │
        ▼ prepareRequest → callAPI(http.Client.Do)
        │
        ▼ decode → *Sandbox  (model_sandbox.go)
```

### `APIClient`(`client.go:47-90`)

```go
type APIClient struct {
    cfg    *Configuration
    common service                          // 单实例共享给所有 Service
    AdminAPI          AdminAPI              // 接口
    ApiKeysAPI        ApiKeysAPI
    ...
    WorkspaceAPI      WorkspaceAPI
}

type service struct { client *APIClient }
```

构造:`NewAPIClient(cfg)` 把同一个 `common service`(内含 `*APIClient` 回指)同时强转成所有 `*XxxAPIService`,每个 service 都拿到同一份 `client` 引用,节省内存。

### `Configuration`(`configuration.go:78-87`)

```go
type Configuration struct {
    Host             string
    Scheme           string
    DefaultHeader    map[string]string
    UserAgent        string
    Debug            bool                  // ← true 时 dump 请求/响应到 log
    Servers          ServerConfigurations  // ← 多 server / 变量模板
    OperationServers map[string]ServerConfigurations  // ← 按 operation 覆盖
    HTTPClient       *http.Client          // ← 注入自定义 transport / 超时
}
```

服务器地址解析:`ServerURLWithContext(ctx, "<OperationId>")`,支持每个 op 单独指定 server(`ContextOperationServerIndices`)+ 变量替换(`ContextOperationServerVariables`)。

### 鉴权:全靠 `context.Value`

```go
// configuration.go:31-46
var (
    ContextAccessToken               = contextKey("accesstoken")
    ContextServerIndex               = contextKey("serverIndex")
    ContextOperationServerIndices    = contextKey("serverOperationIndices")
    ContextServerVariables           = contextKey("serverVariables")
    ContextOperationServerVariables  = contextKey("serverOperationVariables")
)
```

`prepareRequest` 里:
```go
if auth, ok := ctx.Value(ContextAccessToken).(string); ok {
    localVarRequest.Header.Add("Authorization", "Bearer "+auth)
}
```

也就是说,**Bearer token 通过 `context.WithValue(ctx, apiclient.ContextAccessToken, token)` 注入,不需要在 `Configuration` 上保管全局密钥**——一次配置多个调用方独立鉴权很方便。

> 组织上下文用专门的 header(不是 token):每个 Request builder 上都有 `.XBoxLiteOrganizationID(orgID)`,最终落到 `X-BoxLite-Organization-ID` header(见 `api_sandbox.go:532-534`)。

### 错误处理:`GenericOpenAPIError`

```go
// client.go:676
type GenericOpenAPIError struct {
    body  []byte
    error string
    model interface{}
}
func (e GenericOpenAPIError) Error() string
func (e GenericOpenAPIError) Body()  []byte         // 原始响应体
func (e GenericOpenAPIError) Model() interface{}    // 反序列化的错误 DTO(若 spec 定义了)
```

任何 `HTTP >= 300` 的响应都会被包成 `*GenericOpenAPIError`,**响应体保留在 `Body()`**——上层可以根据需要再 unmarshal 到具体 error model。

### Server 多端 + Operation 级覆盖

```go
// 默认所有 op 都走 cfg.Servers[0]
cfg.Servers = []ServerConfiguration{{ URL: "https://api.boxlite.io" }}

// 但你也可以为某个 op 单独换 server / 加变量:
ctx := context.WithValue(ctx, apiclient.ContextOperationServerIndices,
    map[string]int{ "ToolboxAPIService.UploadFile": 1 })
ctx  = context.WithValue(ctx, apiclient.ContextOperationServerVariables,
    map[string]map[string]string{
        "ToolboxAPIService.UploadFile": { "region": "us-east" },
    })
```

这是 OpenAPI 3.x 多 `servers` 字段的标准实现。

## 生成流水线(`project.json:generate:api-client`)

```bash
# 1) 先把 apps/api 的 swagger 导出
nx run api:openapi                                # 产出 dist/apps/api/openapi.json

# 2) 清掉旧的生成文件(保留 api/、go.mod 之类)
rm -f libs/api-client-go/*.go

# 3) 跑 OpenAPI Generator
yarn run openapi-generator-cli generate \
  --git-repo-id=boxlite/libs/api-client-go \
  --git-user-id=boxlite-ai \
  -i dist/apps/api/openapi.json \
  -g go \
  --additional-properties=\
disallowAdditionalPropertiesIfNotPresent=false,\
packageName=apiclient,\
moduleVersion=$DEFAULT_PACKAGE_VERSION,\
generateInterfaces=true,\
enumClassPrefix=true,\
structPrefix=true \
  -o libs/api-client-go

# 4) 后处理(手工补丁:license header / module path / VERSION 等)
bash hack/go-client/postprocess.sh libs/api-client-go apiclient api-client-go
```

关键参数:

| 参数 | 含义 |
|---|---|
| `packageName=apiclient` | Go 包名 |
| `generateInterfaces=true` | **每个 Service 同时生成接口 + 实现**——便于上层 mock |
| `enumClassPrefix=true` | enum 名前加 type 名前缀,避免冲突 |
| `structPrefix=true` | struct 名前加前缀 |
| `disallowAdditionalPropertiesIfNotPresent=false` | 兼容未来字段,见上文 `AdditionalProperties` |
| `moduleVersion=$DEFAULT_PACKAGE_VERSION` | 注入到 `go.mod` |

## 版本与下游联动(`project.json:set-version`)

发版时 `set-version` target 会做三件事:

```bash
# 把当前 VERSION 写到本目录
echo "$VERSION" > libs/api-client-go/VERSION

# 同步更新所有依赖此 client 的下游 go.mod
cd apps/cli                       && go mod edit -require=...api-client-go@$VERSION
cd libs/sdk-go                    && go mod edit -require=...api-client-go@$VERSION
cd apps/otel-collector/exporter   && go mod edit -require=...api-client-go@$VERSION
```

`version.go` 通过 `//go:embed VERSION` 暴露给运行时:

```go
//go:embed VERSION
var _clientVersion string
var ClientVersion = strings.TrimSpace(_clientVersion)
```

这个常量被注入到默认 `User-Agent`(`configuration.go:93`),服务端日志里能看到客户端版本。

## 调用示例(典型用法)

```go
import (
    "context"
    apiclient "github.com/boxlite-ai/boxlite/libs/api-client-go"
)

func main() {
    cfg := apiclient.NewConfiguration()
    cfg.Servers = apiclient.ServerConfigurations{
        { URL: "https://app.boxlite.io/api" },
    }
    client := apiclient.NewAPIClient(cfg)

    ctx := context.WithValue(
        context.Background(),
        apiclient.ContextAccessToken,
        os.Getenv("BOXLITE_API_KEY"),
    )

    sb, resp, err := client.SandboxAPI.
        CreateSandbox(ctx).
        XBoxLiteOrganizationID(orgID).
        CreateSandbox(apiclient.CreateSandbox{
            Snapshot:   apiclient.PtrString("ubuntu:22.04"),
            Cpu:        apiclient.PtrInt32(2),
            Memory:     apiclient.PtrInt32(2048),
            Env:        &map[string]string{"FOO": "bar"},
        }).
        Execute()

    if err != nil {
        if oe, ok := err.(*apiclient.GenericOpenAPIError); ok {
            log.Printf("api error body=%s", oe.Body())
        }
        log.Fatal(err)
    }
    defer resp.Body.Close()
    log.Printf("sandbox %s state=%s", sb.GetId(), sb.GetState())
}
```

## 设计权衡 / 注意事项

1. **零外部依赖**(`go.mod` 没有 require),只用标准库。便于下游引用、避免依赖冲突。
2. **接口先行(`generateInterfaces=true`)**,所有 Service 都是 interface,`*XxxAPIService` 是默认实现。下游可以用 mock 框架替换。
3. **生成器把 `ApiKey` 当成 OpenAPI 资源类型 → service 名 `ApiKeysAPI`**(注意复数);别与 `Configuration.ContextAPIKey` 鉴权类型混淆。
4. **指针风格**:OpenAPI optional 字段一律生成成 `*T`,所以构造 model 时大量出现 `apiclient.PtrString("...")` / `apiclient.PtrInt32(2)`。
5. **`NullableT` ≠ `*T`**:`NullableT` 还能区分 “显式 null”;只有 spec 标了 `nullable: true` 的字段才会用它。
6. **Debug 模式**:`cfg.Debug = true` 会用 `httputil.DumpRequestOut/DumpResponse` 把完整 HTTP 报文打到 `log`——**不要在生产开启**,token 会泄漏。
7. **`callAPI` 不内置重试**——重试/熔断/超时请通过自定义 `cfg.HTTPClient` 的 transport 实现。
8. **不要手改生成的 `.go`**——`generate:api-client` target 的第一步就是 `rm -f *.go`。任何手工补丁都得放进 `hack/go-client/postprocess.sh`,或者上推到 `apps/api` 的 OpenAPI 注解。

## 与其他模块的关系

```
apps/api  (NestJS)
   │
   │  nx run api:openapi
   ▼
dist/apps/api/openapi.json
   │
   │  nx run api-client-go:generate:api-client
   ▼
apps/api-client-go/  ←──────────────  这里
   │  go.mod = github.com/boxlite-ai/boxlite/libs/api-client-go
   │
   ├──► apps/cli                    (boxlite CLI)
   ├──► libs/sdk-go                 (Go SDK 暴露给最终用户)
   └──► apps/otel-collector/exporter
```

所以这是一个 **纯生成产物 + 库**:不部署、不运行、不要手改。所有它的“源代码”实际上是 `apps/api` 上的 NestJS controller + DTO + Swagger 装饰器。
